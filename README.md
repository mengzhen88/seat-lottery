# 好位 · 五人工位抽签

工位候选为 **178、180、181、182、183**，地图保持原始示意图的相对位置。

## 使用

1. 发起人输入五个不同的名字，创建一轮抽签。
2. 点击「复制本轮邀请链接」，将**完整链接（包含 #draw= 后的内容）**发给另外四位伙伴。
3. 大家打开同一链接，选择自己的名字，点击「揭晓我的工位」。
4. 可查看、复制全员结果；要重新抽签，使用「新开一轮」，并重新分享新链接。

## 随机规则与边界

- 创建时使用 Web Crypto 生成随机数，通过无偏 Fisher–Yates 洗牌，为五个名字固定分配五个工位。
- 每个名字有且只有一个固定结果。同一轮链接在不同设备、刷新、重复点击后保持一致，不会重复分配工位。
- 点击揭晓展示已经随机分配的结果，并非请求服务器即时抽号。
- 名单和分配结果编码在 URL fragment 中，GitHub Pages 不需要服务器或数据库。不要把编码当作加密。
- 揭晓进度只保存在当前浏览器，不代表其他人是否揭晓；可以查看全员结果。
- 不验证参与者身份，持有完整链接的人可以选择任一名字和查看全员结果。适用于互相信任的小团队抽签。
- 修改或重建链接意味着另一份结果。请以发起人分享的同一轮完整链接为准。
- 没有第三方分析、外部字体或运行时依赖，不向 GitHub 上传抽签名单；请仅将邀请链接分享给本轮参与者。

## 部署

这是无构建步骤的静态站点。GitHub 仓库 Settings → Pages → Deploy from a branch → main / (root)。入口为 `index.html`。

主要文件：`index.html`、`style.css`、`app.js`。`.nojekyll` 禁用 Jekyll。
